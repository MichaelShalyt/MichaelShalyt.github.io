# Design and Compatibility Notes

## Site shape

1. The site is a static multi-page personal website.
2. Navigation is driven by the page order in [content/site_content.py](D:/Codex%20Projects/Shalyt%20Website%20Migration/content/site_content.py).
3. Shared styling lives in [assets/styles.css](D:/Codex%20Projects/Shalyt%20Website%20Migration/assets/styles.css).

## GitHub Pages compatibility

1. Pages are generated as plain HTML files.
2. Static assets are served from the repository `media` and `assets` folders.
3. There are no server-side dependencies.
